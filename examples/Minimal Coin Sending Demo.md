
# Cardano Example Dapp

## **Minimal Coin Sending Demo**

Instead of using key-value maps for list of block code, here we use arrays and number indexes, making code less self explanatory but much smaller. The 'outputs' property of the 'buildTx' API function allows you to define multi-asset transaction outputs. In Cardano assets are defined by a policyId and an assetName, for ADA we use 'ada' in both cases. Receiver, asset and quantity are exposed as flat arguments so an auto-generated dapp can drive them, and they are checked with assert() before the wallet builds anything. A GameChanger Wallet Dapp Demo. https://gamechanger.finance/
